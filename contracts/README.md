# Versioned Contracts

This directory is the controlled publication boundary for AIArbiTech YouTube OS API and event contracts.

The included files are **compatibility placeholders**, not approved Global Ecosystem contracts. Every capability is marked `NOT_VERIFIED` until the governing enterprise contracts are inspected and approved.

Rules:

1. Contracts are versioned and backward compatibility is explicit.
2. Authentication and authorization are mandatory for cross-platform calls.
3. Correlation and idempotency metadata are mandatory where applicable.
4. No contract permits direct database access.
5. No placeholder authorizes production integration.
