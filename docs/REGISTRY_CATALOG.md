# Registry Catalog

This catalog lists core registries used in AIArbiTech YouTube OS.

## Registry List

| Registry Name | Purpose | Owner |
|---|---|---|
| Creator Registry | Maintain authoritative records of creators, identity references, lifecycle status, and governance metadata for creator entities. | Creator Platform Team |
| Channel Registry | Track channel ownership, channel configuration, moderation state, and channel-level operational metadata across platform workflows. | Channel Operations Team |
| Subscription Registry | Store and govern subscription plans, subscription state transitions, billing linkage, and entitlement visibility for subscribed users/creators. | Subscription & Billing Team |
| Revenue Registry | Record revenue entries, allocation references, payout-relevant metrics, and audit-friendly revenue lineage across monetization flows. | Finance Operations Team |
| Monetization Registry | Manage monetization models, eligibility rules, monetization policy mappings, and feature enablement for revenue programs. | Monetization Strategy Team |
| AI Director Registry | Catalog AI director policies, prompt governance metadata, approved AI directives, and execution guardrails. | AI Governance Team |
| AI Decision Registry | Persist AI decision outcomes, confidence/context metadata, explainability traces, and decision audit records. | AI Platform Team |
| Workflow Registry | Register workflow definitions, orchestration versions, state models, and execution policy constraints for automation flows. | Workflow Orchestration Team |
| Configuration Registry | Maintain platform configuration inventory, versioned configuration keys, environment overlays, and change-control metadata. | Platform Configuration Team |
| API Contract Registry | Version and govern API contracts, schema compatibility status, and integration approval records for internal/external API consumers. | API Governance Team |
| Event Contract Registry | Version and govern event schemas, topic ownership, compatibility constraints, and event lifecycle policy for async integrations. | Event Governance Team |
