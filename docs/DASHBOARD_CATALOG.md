# Dashboard Catalog

This catalog lists YouTube OS dashboard and panel surfaces with visibility, key information, allowed controls, and governance limits.

## Dashboard List

| Dashboard | Who Can View | What They See | What They Can Control | What They Cannot Control |
|---|---|---|---|---|
| President Dashboard | President | Strategic platform status, KPI trends, risk summary, AI and operations overview, delegated task visibility. | Strategic direction, delegation decisions, approval decisions at strategic level. | Daily operational execution, direct financial transfer, local RBAC override, bypassing audit/governance process. |
| Heir Dashboard | Heir | High-level governance metrics, strategic continuity status, delegated decision context, critical platform signals. | Strategic follow-up decisions within approved governance scope. | Financial management and money transfer, unauthorized authority escalation, direct runtime operations. |
| Admin Dashboard | Admin | Operational exception queue, system health state, moderation and support operations, automation coverage status. | Resolve approved operational exceptions, execute admin workflows, apply governed operational actions with audit. | Strategic enterprise authority, local identity/auth policy ownership, unaudited critical actions, cross-platform DB access. |
| Creator Dashboard | Creator | Channel summary, content and publishing status, analytics snapshots, goal/progress views, alerts and recommendations. | Creator-facing preferences and approved self-service actions in own workspace scope. | Platform governance changes, cross-context private data access, financial truth control, security policy override. |
| AI Director Dashboard | AI Director | AI directive status, recommendation queues, execution rationale, model response trace references, policy compliance indicators. | Propose and coordinate AI directives, route approved AI-driven tasks, monitor directive outcomes. | Self-granting new authority, bypassing approval/audit, local AI Core replacement, changing enterprise AI policy. |
| Workflow Dashboard | Admin, AI Director, President, Heir | Workflow state map, step status, approvals, blocked stages, execution latency and completion trends. | Start/advance approved workflows, assign steps, track and resolve governed workflow exceptions. | Replacing Global workflow engine, executing unapproved workflow templates, bypassing authentication/authorization contracts. |
| Monitoring Dashboard | Admin, President, Heir, AI Director | Service uptime, API latency, error rates, infrastructure metrics, alert states, incident indicators. | Observe and acknowledge incidents, trigger approved operational response procedures. | Reconfiguring prohibited architecture boundaries, disabling required audit/security controls, replacing Global monitoring ownership. |

## Notes

- This catalog defines governance-aligned dashboard responsibilities. It does not itself grant runtime permissions.
- Dashboard capabilities must remain consistent with platform boundaries, architecture protection, and change management controls.
